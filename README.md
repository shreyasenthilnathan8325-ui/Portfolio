# Premium Personal Portfolio

A reusable, dark-first, editorial personal portfolio framework built with pure HTML, CSS, and vanilla JavaScript.

## Files

- `index.html`
- `about.html`
- `career.html`
- `academic-journey.html`
- `skills.html`
- `experience.html`
- `projects.html`
- `achievements.html`
- `courses.html`
- `publications.html`
- `contact.html`
- `css/styles.css`
- `js/main.js`
- `assets/images/`
- `assets/icons/`
- `assets/documents/`

## Customization

1. Replace `YOUR NAME`, role text, metadata, social links, and placeholder copy.
2. Add the profile image at `assets/images/profile.jpg` if desired.
3. Add the résumé at `assets/documents/resume.pdf`.
4. Change `--accent` in `css/styles.css` to change the site's accent color globally.
5. Add your Formspree endpoint to `contact.html`.
6. Replace project, experience, academic, course, achievement, and publication placeholders with verified information.

The framework intentionally does not assume a profession, degree, industry, gender, or career path.

## Local use

Open `index.html` in a browser. For the cleanest development experience, serve the folder with any simple local static server.

## GitHub Pages

Keep the relative links and folder structure unchanged. The navigation is based on `window.location.pathname`, so it is suitable for GitHub Pages subpaths as well.
